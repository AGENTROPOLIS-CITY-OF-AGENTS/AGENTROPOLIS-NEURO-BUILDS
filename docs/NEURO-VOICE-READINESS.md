# NEURO Voice Readiness

NEURO supports communication readiness and continuity for the AGENTROPOLIS Voice Utility Grid.

NEURO is not the TTS engine and does not unilaterally grant speaking authority.

## NEURO responsibilities

- conversational context
- semantic emphasis recommendations
- turn-taking awareness
- interruption/yield recommendations
- delivery-state continuity
- persona consistency
- memory continuity
- drift detection between intended meaning and rendered delivery
- readiness evidence for voice promotion/review

## Separation of duties

```text
NEURO -> evaluates readiness/context
ATG:VOICE -> expresses speech intent
AEGIS/policy -> grants or denies authority
Voice Gateway -> routes execution
Voicebox/provider -> renders speech
Channel adapter -> publishes speech
Audit -> preserves receipt
```

An agent may remain permanently text-only. Voice is an earned utility, not a creation default.
